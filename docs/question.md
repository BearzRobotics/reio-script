# Questions for the designer

These are the points I could not settle from the three charts and Canepari's free book. The first one matters most because it changes the labels on half the rows.

## 1. Within each pair of rows, which is voiced and which is voiceless?
The 36 rows decode as 18 manners of articulation, two rows each (7 groups of 2, 3, 1, 1, 2, 4 and 5 manners). I labelled the **first** row of each pair **voiced** and the **second voiceless**. The only evidence is that in chart 16180 the first row of each nasal pair is blue and the second is nearly empty, which fits voiced first (voiceless nasals are rare). The charts themselves do not say. Is that the right order for all seven groups?

## 2. What is the small 5 by 6 grid at the top right of each chart?
It has red marks on the left (in pairs, numbered 1 to 6) and red marks along the top (five of them), and each ring in it has a different inner mark. I left it undecoded. Is it a legend of the ring's building blocks, a vowel or other table, or something else?

## 3. What do the red marks along the top and left edges encode?
I treated them as labels, one per column and one per row, and did not put them in the font. Do they also describe how the ring is built (for example, the top mark gives the place, the left mark gives the manner)? If so I can document the construction rules, and possibly build the glyphs as composed parts instead of tracing them.

## 4. Is there a legend that names each glyph?
I matched the grid to Canepari's fig 10.1 by counting (the 13 place families have 5, 5, 7, 6, 6, 5, 4, 5, 5, 6, 4, 3, 2 positions, an exact match). I did not attach Canepari's own symbol to each cell. If you have a table of glyph to canIPA symbol, I can add it.

## 5. Where does the blue "found in human speech" set come from?
566 of 2,268 cells are blue in chart 16180. In every spot check (11 cells) it agreed with Canepari's table, but his table only covers about 70% of articulations. Is the blue set taken from Canepari's full lists, or from another source?

## 6. Naming and credit
- Should the font be called **RE_iO Script**? The chart file name uses a person symbol before it (웃RE_iO).
- Is the credit line right? I used: "based upon work by Luciano Canepari, La Fonetica naturale, con IPA", as printed on the charts.

## 7. Licence and sharing
No licence is set. Who should be credited as the author, and under what terms should the font be shared (for example SIL Open Font License for the font, something else for the charts)? Canepari's PDFs are free to download from canipa.net but I have not checked whether they may be redistributed, so they are linked from `upstream/`, not copied.

## 8. Typing
The 4-key codes follow the chart's own groups. Would the designer prefer a different scheme, such as one key per place family and one per manner?
